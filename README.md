# derbyprod
Данные: база данных ФАО по мировому производству (переработке) рыбной продукции

Определения и ограничения: В файле pp_ddl.sql ddl-структура базы данных Apache Derby Embedded (последняя версия derby 10.17.1.0 совместимость Java 21+) с описанием контента в комментариях. В папке /CSV лежат .csv дампы таблиц этой базы данных, включая основную таблицу данных TSD_TRADE_PP_QUANTITY, остальные таблицы либо описательные списки REF_ либо реляционные REL_. Поля не описанные комментариями в DDL, за исключением полей с одинаковым именем описанных один раз за все повторяющиеся аналоги, - не имеют никакого значения и игнорируются. В базе много полей с именованиями на языке отличном от английского - они игноруются, используются только поля _EN (английский язык). SQL-запросы создаются в диалекте Apache Derby (обязательно), диалект Derby является крайне ограниченным по сравнению с современным SQL и при этом обязателен для доступа к базам derby, поэтому надо учитывать тонкости и ограничения диалекта.
Вывод делается без дополений в данные базы данных, as is, имена стран такие как в базе, виды как в базе, без изменений и дополнений, если не указано обратное.
Не надо создавать дополнительные алгоритмы загрузки драйверов из интернета в программах, только обработка файлов согласно плану задания.
Нумерация колонок на стадии SQL-запросов и python-обработки только для понимания логики, никакая нумерация при оформлении не нужна.
"Последние 5 лет" в данный момент это 2020-2024 гг.
